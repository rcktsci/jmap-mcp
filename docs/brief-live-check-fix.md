# Бриф: починка зонда live_check (2 артефакта)

Дата: 2026-10-27. Роль: **разработчик**. Репо: `rcktsci/jmap-mcp`. Файл: `tools/live_check.py`.

Живой сервер подтвердил: оба «error» в матрице — артефакты зонда, а не сервера и не тулов.

1. **Проверка №10 (`Email/get`: textBody против bodyValues) падает 400.**
   Причина: зонд шлёт `bodyProperties` как **dict** `{"maxLength": 2000, "textBody": True, "htmlBody": True}`.
   По RFC 8621 §4.2 `bodyProperties` — это `String[]`. Сервер отвечает 400.
   Правка: `bodyProperties` → список строк, например `["partId", "blobId", "size", "type", "charset"]`.
2. **Проверка №12 (`state`) выдаёт «Email/changes is refused: invalid JMAP State».**
   Причина: зонд подставляет `sessionState` (например `cbb4eb6c`), а `Email/changes` требует
   **account state** — тот, что возвращается в ответе `Mailbox/get` / `Email/query` (например `sbu`).
   Правка: взять state из ответа `Mailbox/get` (поле `state`), подставить его в `Email/changes`;
   в доказательстве показать оба значения и факт 200.
